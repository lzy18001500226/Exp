# 1 设计要点概览

## 术语定义（统一）

- 条件化跨注意力（Conditional Cross-Attention）
  - Level 1（简单）：vts_valid=0 时跳过交互，返回 Q（恒等映射）；适用于 B3–B4 的快速稳健做法。
  - Level 2（完整）：构造 attn_mask 将缺失模态样本的 K/V 注意力分数置为 -inf；适用于 B6 的严格实现。
- 零化（Zero-filling）：当模态缺失时，将该分支的特征置为 0（需配合 presence embedding/flag 避免偏移）。
- Presence flag / embedding：
  - presence flag：为每样本附加模态有效性标志（如 vts_valid），与特征一起送入分类头；
  - presence embedding：当模态缺失时，在特征层级（融合前）用一个可学习向量替代该模态特征，缓解分布偏移（而非在分类阶段再附加）。
- 门控（Gating）：用 g∈(0,1) 融合两模态通道特征（B5 简版；B6 使用 DMG_v2 完整版）。

- B6 核心创新点（与常规 Bi-Attn 区分）：Conditional Bi-Cross-Attn（按样本屏蔽的跨注意力）+ 动态门控 DMG_v2（含 flags/尺度提示/温度），并在融合后接 Temporal Transformer 建模伪时间。

* 任务：DroneRFb-Spectra 双模态分类（FCS + VTS） → 24 类（23 UAV + background），并支持开放集识别。
* 原始数据：`.npy` 单通道 float16，shape `(543, 512)`（time × freq），已归一化到 `[0,1]`。
* 决策：统一将输入 resize 到 `512×512`（保留大部分时间信息、与预训练模型兼容、加速矩阵运算）。
* Backbone：`Swin-Base`（FCS） + `ConvNeXt-Base`（VTS），均按单通道输入适配。
* 融合：**Bi-Cross-Attention (双向跨模态注意力)** +  **Dynamic Modality Gating (DMG, 通道级)** 。
* 时序： **Temporal Transformer** （pseudo-time chunking, 2–4层）用于隐式多普勒时序建模。
* 分类头：GAP → LN → FC → Softmax；可选 CenterLoss/ArcFace。
* 训练策略：预训练权重迁移 + 冻结-解冻分阶段微调 + AdamW + Cosine LR + FP16。

# 2 数据与预处理（精确流程）

## 2.1 原始数据

* 每个原始 `.npy`：`spec` shape `(543, 512)`, dtype `float16`, values ∈ [0,1], 无 NaN/Inf。

## 2.2 统一尺寸与精度

* **统一尺寸** ：将 `(543,512)` 缩放到 `(512,512)`。
* 理由：减少实现复杂度、与 patch/窗口注意力对齐、提高 GPU 并行效率。
* 方法：`cv2.resize(spec, (512,512), interpolation=cv2.INTER_AREA)`（对时间轴进行下/上采样，频率轴保持原比例到 512）。
* **数据类型** ：加载为 `float32`（模型前端使用 float32，训练时启用 FP16 AMP）。

## 2.3 训练阶段增强（pipeline）

在 `Dataset.__getitem__` 中按概率或顺序应用（均在 `.npy` float32 基础上）：

1. **背景混合** ：`spec = (1-α)*spec + α*bg_noise`，`α ∈ U(0.1,0.3)`（bg_noise 从 Class0 随机抽样）。
2. **频率偏移（多普勒）** ：`spec = np.roll(spec, shift=s, axis=1)`，`s ∈ IntUniform(-s_max, s_max)`，`s_max` 对应 ±10 MHz → 像素换算 = `round(10MHz / (bandwidth/512))`。
3. **时间拉伸** ：`time_scale ∈ U(0.9,1.1)`，先按 time 轴缩放后 resize 回 512。
4. **高斯噪声** ：按 SNR ∈ [10,30] dB 添加噪声。
5. **SpecAugment（保守）** ：time/freq mask 比例 ≤ 0.2。
6. **（可选）ColorMap** ：训练直接用单通道值，**不要**把数据映射为 RGB PNG（量化误差）。

### 2.3.1 增强策略约束（新增）

为避免过度增强导致不真实样本，采用分级与互斥策略：
- 互斥组：
  - 噪声增强二选一：背景混合 或 高斯噪声；
  - 失真增强最多选一：频移 或 时间拉伸；
  - Masking 独立低概率：SpecAugment（mask_ratio ≤ 0.2）。
- 强度调度：随 epoch 逐步降低增强强度（后期更干净）。
- 有效性验证：增强后做能量/频谱相关性检查，拒绝过度破坏样本。
- 背景混合策略：背景 Class0 采用“类间混合”（全局背景池随机抽样），避免类条件信息泄露；可选同域约束（同采集条件）。
- 频谱一致性阈值：建议保留 corr(spec, spec_aug) ≥ 0.7 的增强样本（相关性不足则回退原样本）。

实现示例（伪代码）：
```python
# 基础概率（可配置）
p_noise=0.7; p_dist=0.5; p_mask=0.3
if rand()<p_noise: spec = bg_mix(spec) if rand()<0.5 else add_gaussian_noise(spec)
if rand()<p_dist: spec = freq_shift(spec) if rand()<0.5 else time_stretch(spec)
if rand()<p_mask: spec = spec_augment(spec, mask_ratio<=0.2)
# 强度调度示意：前强后弱；有效性校验不通过则回退原样本
```

## 2.4 标注映射

* 你在 PNG/图上标注的位置应相对 `(512,512)` 保存；由于你统一为 `512×512`，标注无需再“反映射”。若原标注在 `(543,512)` 上，需一次性映射到 `(512,512)`（scale/time axis map）。

# 3 张量与形状约定（全文）

* Batch: `B`
* Input per modality: `[B, 1, 512, 512]`
* Swin / ConvNeXt backbone output (Stage4): `[B, C_back, H, W]`，建议 `C_back = 1024`, `H = W = 16` → `N = 256` tokens.
* After flatten: `[B, N, C_back]`
* Project to embedding: `E = 512` ⇒ `[B, N, E]`
* Temporal chunking: `T` chunks ≈ 8 (default), chunk_len = `N/T = 32` → Temporal seq `[B, T, E]`
* Final feature vector: `[B, E]` → classifier → `[B, num_classes]`

# 4 Backbone 适配（细节）

## 4.1 单通道适配方案

* 对于 Swin/ConvNeXt 的第 1 个卷积（patch embed/stem），权重形状原为 `[out_ch, 3, k, k]`：
  * 新权重初始化：`new_w = pretrained_w.mean(dim=1, keepdim=True)` → `[out_ch, 1, k, k]`。
* 其余权重（norm、blocks、attn）直接加载预训练值。
* 实现建议：载入 checkpoint → 替换第一层权重 → `load_state_dict(..., strict=False)`。

## 4.1.1 Swin 窗口对齐建议（512×512 输入）

- 为保证 512×512 与 Swin 的 window 对齐，建议使用 window_size=8（因为 512/4=128，128/8=16 可整除）。
- 若使用 window_size=7 的预训练权重，可在加载后将运行配置改为 window_size=8 并使用 strict=False（位置偏置可插值/重新初始化）。
- 备选：改输入尺寸为 448 或 560（使 window_size=7 可整除）。

### 4.1.1.1 窗口尺寸适配实现（重要）

问题：预训练权重 window_size=7，运行需 window_size=8 时，相对位置偏置表形状不匹配，strict=False 会跳过加载，性能显著下降。

解决：
- 显式插值（推荐）：对所有 `relative_position_bias_table` 做双三次插值，将 (2·7-1)^2 → (2·8-1)^2；加载后检查 missing/unexpected 关键字，确保位置偏置已加载。
- 动态实现：使用支持任意 window_size 的实现（部分 timm 版本会自动插值）。
- 备选：保持 window_size=7，改输入为 448 或 560。

验证：冻结 backbone 只训头部 10 epochs，比对验证精度；若位置偏置未正确迁移，精度会明显下降。

## 4.2 冻结策略

* 阶段 A（fusion warm-up）: 冻结 backbone 的大部分层（例如前 3 个 stage），仅训练 stage4、proj layers、fusion、temporal、head。训练 5–10 epoch。
* 阶段 B：按 layer-wise lr decay 解冻更多层，最终微调全部或大部分权重。

# 5 Bi/Conditional Cross-Attention（融合模块） — 更新

## 5.1 目标

* 双向跨模态信息交换，且在模态缺失/噪声时不引入伪特征。

## 5.2 条件化策略（按样本屏蔽）

- Level 1（简单，B3–B4）：当 vts_valid=0 时“跳过该层”，直接返回 Q，不进行跨注意力计算；
- Level 2（完整，B6）：在注意力打分阶段对缺失样本的 K/V 进行屏蔽：
  - 按样本构造 attn_mask（或 key_padding_mask），对该样本所有 K/V 位置赋 -inf（布尔 mask 置 True）;
  - 使注意力权重在算子级无效化，而非仅在输出处相乘；
  - 若出现“全屏蔽”引发数值异常，回退为恒等（返回 Q）。
- 接口建议：`mode ∈ {"simple","full_mask"}`，分别对应 Level 1/Level 2。

## 5.3 相对/绝对位置编码（可选）

* 选项：
  * 相对位置偏置（Swin 风格）用于 16×16 网格的跨注意力；
  * 绝对位置编码（ViT 风格）；
  * 时频分解位置编码（time/freq 正弦编码后拼接）。

## 5.4 伪代码（精简）

```python
class ConditionalCrossAttn(nn.Module):
    def __init__(self, E=512, heads=8, attn_drop=0.1, drop=0.1):
        super().__init__()
        self.attn = nn.MultiheadAttention(E, heads, dropout=attn_drop, batch_first=True)
        self.norm1 = nn.LayerNorm(E, eps=1e-6)
        self.mlp = nn.Sequential(nn.Linear(E, 4*E), nn.GELU(), nn.Dropout(drop), nn.Linear(4*E, E), nn.Dropout(drop))
        self.norm2 = nn.LayerNorm(E, eps=1e-6)

    def forward(self, Q, K, V, modality_valid: torch.Tensor, attn_mask=None):
        # modality_valid: [B,1]，0=无效 → 屏蔽跨模态输出
        attn_out, _ = self.attn(Q, K, V, attn_mask=attn_mask)
        attn_out = attn_out * modality_valid.unsqueeze(-1)  # 缺失样本置零
        x = self.norm1(Q + attn_out)
        x = self.norm2(x + self.mlp(x))
        return x
```

# 6 Dynamic Modality Gating（DMG_v2） — 更新

## 6.1 设计目标

* 在模态存在/缺失下输出可解释、稳健的门控；避免“无对比信息”导致的退化/崩塌。

## 6.2 输入与归一化（维度与形状）

- f_gap, v_gap ∈ R^{B×E}：由 token 特征做 GAP（通道维 E）。
- 归一化：f_norm, v_norm ∈ R^{B×E} 为 L2 归一化后的向量；
- 尺度提示：s_f, s_v ∈ R^{B×1}（由未归一化的范数缩放得到）;
- 模态标志：flags = [fcs_valid, vts_valid] ∈ R^{B×2}；
- 门控维度：g ∈ (0,1)^{B×E}（通道级），对所有 token 共享该通道权重，即 fused = g·F_tokens + (1-g)·V_tokens（在 token 维上广播）。

## 6.3 门控与温度（公式化）

- 令 x = [f_norm; v_norm; s_f; s_v; flags] ∈ R^{B×(2E+4)}；
- g = σ((W2·GELU(W1·x))/τ)，其中 τ 为可学习的标量温度（sigmoid 的温度缩放，τ 越大越平滑）。
- learnable scale（位置与含义）：对 F_tokens/V_tokens 的通道尺度自适应参数，作用于 token 特征输入侧（在 GAP 之前），以对齐两模态量纲与动态范围。

## 6.4 损失与正则

* 缺失样本监督：`L_gate_miss = α * ||g - 1||^2`（仅 vts_valid=0），`α: 1.0 → 0.01` 逐步衰减；
* 多样性正则（替代 g≈0.5）：`L_div = -γ * std(g).mean()`，鼓励样本间分散，`γ` 小；
* （可选）软区间正则（有 VTS）：鼓励 `g ∈ [0.2, 0.8]`，采用 soft-clamp。

### 6.4.1 损失调度策略（新增）

问题：分类损失与门控缺失监督可能產生梯度冲突，导致震荡。

方案：
- 分阶段启用（推荐）：Epoch 0–10 关闭 gate loss；10–30 线性增至 1.0；30+ 线性衰减到 0.1。
- 动态权重：按 `loss_cls` 大小自适应调整 α（分类难时降低门控权重）。
- 软目标区间：对 vts_valid=0，鼓励 g∈[0.9,1.0] 的软约束，替代硬性 g=1。

## 6.5 分支解耦（可选）

* 为单/双模态样本用不同 MLP 头（参数共享底层可选），缓解梯度冲突；或通过 loss reweighting 平衡。

## 6.6 伪代码

```python
class DMG_v2(nn.Module):
    def __init__(self, E=512, hidden=None, learnable_tau=True):
        super().__init__()
        hidden = hidden or E//2
        self.mlp = nn.Sequential(nn.Linear(2*E + 2 + 2, hidden), nn.ReLU(), nn.Linear(hidden, E))
        self.tau = nn.Parameter(torch.tensor(2.0)) if learnable_tau else 2.0
        # 可选：通道尺度自适应
        self.scale_f = nn.Parameter(torch.ones(1, E))
        self.scale_v = nn.Parameter(torch.ones(1, E))

    def forward(self, F_tokens, V_tokens, fcs_valid, vts_valid):
        F_tokens = F_tokens * self.scale_f.unsqueeze(1)
        V_tokens = V_tokens * self.scale_v.unsqueeze(1)
        f_gap = F_tokens.mean(1)
        v_gap = V_tokens.mean(1)
        f_n = F.normalize(f_gap, dim=-1)
        v_n = F.normalize(v_gap, dim=-1)
        s_f = f_gap.norm(dim=-1, keepdim=True) / 10.0
        s_v = v_gap.norm(dim=-1, keepdim=True) / 10.0
        gate_in = torch.cat([f_n, v_n, s_f, s_v, fcs_valid, vts_valid], dim=-1)
        logits = self.mlp(gate_in)
        g = torch.sigmoid(logits / self.tau)
        # 缺失样本强制退化到 FCS
        g = g * vts_valid + (1 - vts_valid)
        fused = g.unsqueeze(1) * F_tokens + (1 - g).unsqueeze(1) * V_tokens
        return fused, g
```

# 7 时序建模（改进建议） — 更新

## 7.1 优先使用真实时间轴

* 若谱图某轴对应真实时间（如 512）：对时间轴做序列建模（沿频率做 pooling），使用因果 mask 的 Transformer；
* 无确切时间轴时：
  * 方案A：TCN/1D temporal conv（更稳健更轻量）;
  * 方案B：pseudo-time chunking（原方案），同时对比不同 T∈{4,8,16}；
  * 方案C：多尺度时序并联，线性融合。

## 7.2 多尺度伪代码（摘要）

```python
class MultiScaleTemporal(nn.Module):
    def __init__(self, E=512, Ts=(4,8,16)):
        super().__init__()
        self.encoders = nn.ModuleList([TemporalEncoder(E, T=t) for t in Ts])
        self.fuse = nn.Linear(len(Ts)*E, E)
    def forward(self, tokens):
        feats = [enc(tokens)[1] for enc in self.encoders]
        return self.fuse(torch.cat(feats, -1))
```

# 9 训练细节（两阶段与稳定性） — 更新

## 9.1 两阶段

* 阶段A（单模态预训练）：分别在 FCS-only、VTS-only 样本上训练各自 encoder；保存 backbone；
* 阶段B（融合微调）：冻结/小 lr 解冻 backbone；重点训练 CrossAttn+DMG+Temporal+Head；
* 学习率建议：`backbone_lr=5e-5`, `fusion_lr=1e-4`，cosine + warmup(1k)；
* 采样：保证 batch 内含有 有/无 VTS 样本（或按 epoch 动态权重）。

## 9.2 损失日程

* `L_gate_miss`（vts_valid=0）α: 1.0 → 0.01；
* 多样性正则 `γ` 小幅常数；
* 可选：有 VTS 样本的软区间正则（弱监督）。

## 9.3 数值稳定

* 使用 LayerNorm eps=1e-6；必要时替换为稳定 LN（方差最小值裁剪）;
* AMP 训练下检测 NaN/Inf，跳过异常 batch；
* 梯度裁剪 `clip_grad_norm_=1.0`，监控全局 grad norm；
* Cross-Attn 中避免全部屏蔽导致的无定义：分支回退为恒等（返回 Q）。

## 9.4 采样策略（补标前后）

- 补标前（VTS 样本占比≈12.5%）：

  - 使用“模态平衡采样”强制 batch 内 vts_valid=0/1 均衡（例如 vts_ratio=0.5），并结合两阶段训练；
  - 对 vts_valid=0 的样本启用较强的门控监督（α 高→低衰减），避免 g 学到恒定策略。

- 补标后（with_vts≈50%）：

  - 方案A（推荐）：轻度平衡（vts_ratio=0.5），此时过采样率低，更自然；
  - 方案B：自然采样 + 类别平衡（每类定额抽样），保证类内均衡；
  - 可选：按模态频率自适应权重 w=1/(p_modality+ε)，随 epoch EMA 更新；
  - 一直保持“按类×模态”分层抽样或统计监控，避免批次内模态极端失衡。

## 9.5 开放集类别划分策略

- 主实验（推荐“混合划分”）：

  - 已知类：例如 16 个（其中 8 个有 VTS + 8 个无 VTS）；
  - 未知类：例如 6 个（其中 3 个有 VTS + 3 个无 VTS）；
  - 先用 `Tools/统计/summarize_modalities.py` 获取 `classes_with_vts`/`classes_without_vts`，再随机抽取并固定种子；
  - 生成 `known_classes.txt` 与 `unknown_classes.txt` 并落盘，评估时据此计算 TKR/TUR/KP/H/OSA，同时分别在 vts_valid=0/1 子集上出表。

- 消融（按 VTS 分组）：

  - 实验1：仅在 with_vts 子集中划分已知/未知；
  - 实验2：仅在 without_vts 子集中划分已知/未知；
  - 用于分析 VTS 对开放集识别的具体贡献。

# 10 开放集划分与复现实验步骤（详案）

## 10.1 划分方案A：混合划分（推荐）

目标：在已知/未知类中同时覆盖 with_vts 与 without_vts，考察缺失/存在VTS两种情形下的开放集鲁棒性。

- 实验2（without_vts-only）：K ⊂ without_vts_pool，U ⊂ without_vts_pool，K ∩ U = ∅

# 11 评估指标与实验设计（合并）

## 11.3 融合/门控可观测性（度量定义补充）

- 门控均值差：ΔE[g] = E[g | vts_valid=1] - E[g | vts_valid=0]（越大表示门控对模态状态更敏感）。
- 门控熵：H(g) = -g·log g - (1-g)·log(1-g)（对通道与样本取均值），反映门控不确定性；
- 稳定性：epoch 内/间方差 Var(g)；
- Collapse 检测：若样本-通道维 std(g) < 0.05 触发告警（与 6.7 对应）。

### 11.3.1 批次级门控直方图记录（新增）

目的：快速发现门控分布异常（如集中于 0/1、双峰错位、与 vts_valid 无关等）。

- 记录频率：每 epoch 前 K 批或每 N steps（默认 N=200）抽样一次；训练与验证均可开启（验证优先）。
- 拆分统计：同时保存以下直方图（bins=20，范围 [0,1]）：

  - 全体：g.flatten()；
  - with_vts：g[vts_valid=1].flatten(); without_vts：g[vts_valid=0].flatten();
  - 可选：按通道方差 Top-16 通道分别绘制（排查特定通道坍缩）。
- 文件落盘：`{exp_dir}/gate_hist/epoch_{:03d}/step_{:06d}_{split}.png`，同时将直方图计数写入 `gate_hist.jsonl`（便于后续统计）。
- 日志：TensorBoard `add_histogram('gate/{split}', g_masked, step)` 或 W&B `wandb.Histogram`；建议两者二选一以控体积。
- 采样控制：

* 阈值策略：按类百分位（如 p95）；可选 EVT/Weibull 提升稳健性；
* 推理规则：若样本至其预测类中心的距离 > 该类阈值，则判为 Unknown；
* 校准建议（对比报告）：
  - 多阈值：区分 with_vts / without_vts 两套阈值；
  - 温度缩放：在验证集拟合 temperature，对 logits 进行校准后再阈值化；
  - 置信度调节：以最大 softmax 置信度对阈值做轻微线性修正。

### 11.5.1 阈值鲁棒性增强（新增）

为应对验证/测试分布漂移（如 VTS 有效率差异），增强阈值稳健性：
- 自适应校准：用测试集前 K 个 batch 的无标签距离统计，按类对阈值做缩放校准；
- 分模态阈值：分别在 vts_valid=1/0 上计算阈值；若无 vts_valid=0 数据，可将 with_vts 阈值放宽例如 ×1.2；
- 鲁棒统计量：以 MAD（中位数绝对偏差）替代 std，降低离群点影响；
- 报告：同时给出 baseline（固定阈值）与 calibrated（校准/分模态/MAD）结果对比。

# 12 统一模型骨架与伪代码（可执行逻辑）

为保证基线（B0–B6）可比与可复现，提供统一的模型骨架与可插拔模块。不同基线仅通过配置开关切换模块。

## 12.1 模型骨架（BaseFusionModel）

```python
class BaseFusionModel(nn.Module):
    def __init__(self, config):
        super().__init__()
        # 1) Backbone（单通道适配后的实现）
        self.encoder_fcs = SwinEncoder(in_ch=1, out_dim=config.embed_dim)
        self.encoder_vts = ConvNeXtEncoder(in_ch=1, out_dim=config.embed_dim)

        # 2) 可选模块
        self.cross_attn_fv = ConditionalCrossAttn(E=config.embed_dim, mode=config.attn_mode) \
            if config.use_cross_attn_fv else None
        self.cross_attn_vf = ConditionalCrossAttn(E=config.embed_dim, mode=config.attn_mode) \
            if config.use_cross_attn_vf else None
        self.use_gate = config.use_gate
        if self.use_gate:
            self.gate = DynamicGate(E=config.embed_dim)  # DMG_v2 别名
        else:
            # B2 使用专用的拼接融合（含 presence emb/flag）
            self.concat_fusion = ConcatFusion(E=config.embed_dim, use_flag=True, use_presence_emb=True)

        # 3) Temporal（仅支持门控路径 B5/B6）
        self.use_temporal = config.use_temporal
        if self.use_temporal and not self.use_gate:
            raise ValueError("Temporal module requires gate fusion (use_gate=True)")
        self.temporal = TemporalTransformer(E=config.embed_dim, T=getattr(config, 'temp_chunks', 8)) \
            if self.use_temporal else None

        # 4) 分类头（门控=E；拼接=2E+1）
        head_in = config.embed_dim if self.use_gate else (2*config.embed_dim + 1)
        self.cls_head = nn.Sequential(nn.LayerNorm(head_in), nn.Linear(head_in, config.num_classes))

    def forward(self, fcs, vts, vts_valid):
        # 编码
        f = self.encoder_fcs(fcs)  # [B,N,E]
        v = self.encoder_vts(vts)  # [B,N,E]

        # 条件化跨注意力（按基线开关/模式）
        if self.cross_attn_fv is not None:
            f = self.cross_attn_fv(Q=f, K=v, V=v, modality_valid=vts_valid)
        if self.cross_attn_vf is not None:
            v = self.cross_attn_vf(Q=v, K=f, V=f, modality_valid=vts_valid)

        # 分支融合（方案B）
        if self.use_gate:
            # 门控路径（B5/B6）
            fused_tokens, gate_weights = self.gate(f, v, vts_valid)  # [B,N,E], [B,E]
            # 时序（可选）
            if self.use_temporal:
                x = self.temporal(fused_tokens)  # [B,E]
            else:
                x = fused_tokens.mean(1)  # [B,E]
        else:
            # 拼接路径（B2/B3/B4 不使用 temporal）
            x = self.concat_fusion(f, v, vts_valid)  # [B, 2E+1]

        # 分类
        logits = self.cls_head(x)
        return (logits, gate_weights) if self.use_gate else logits
```

## 12.2 条件化跨注意力（Level1/Level2）

```python
class ConditionalCrossAttn(nn.Module):
    """
    条件化跨模态注意力
    mode: 'simple' (Level1) 或 'full_mask' (Level2)
    """
    def __init__(self, E=512, heads=8, mode='simple', attn_drop=0.1, drop=0.1):
        super().__init__()
        self.mode = mode
        self.attn = nn.MultiheadAttention(E, heads, dropout=attn_drop, batch_first=True)
        self.norm1 = nn.LayerNorm(E, eps=1e-6)
        self.mlp = nn.Sequential(
            nn.Linear(E, 4*E), nn.GELU(), nn.Dropout(drop), nn.Linear(4*E, E), nn.Dropout(drop)
        )
        self.norm2 = nn.LayerNorm(E, eps=1e-6)

    def forward(self, Q, K, V, modality_valid: torch.Tensor):
        B, Nq, E = Q.shape
        # Level 1：输出级别屏蔽（简单、稳健）
        if self.mode == 'simple':
            if modality_valid.sum() == 0:
                return Q
            attn_out, _ = self.attn(Q, K, V)
            attn_out = attn_out * modality_valid.view(B, 1, 1)  # 缺失样本置零
            x = self.norm1(Q + attn_out)
            x = self.norm2(x + self.mlp(x))
            return x

        # Level 2：key_padding_mask 的算子级屏蔽（严格）
        elif self.mode == 'full_mask':
            Nk = K.size(1)
            key_padding_mask = torch.zeros(B, Nk, dtype=torch.bool, device=Q.device)
            missing = (modality_valid.view(B) == 0)
            key_padding_mask[missing, :] = True
            if missing.all():
                return Q  # 全缺失回退恒等
            try:
                attn_out, _ = self.attn(Q, K, V, key_padding_mask=key_padding_mask)
            except RuntimeError:
                return Q  # 数值异常回退恒等
            x = self.norm1(Q + attn_out)
            x = self.norm2(x + self.mlp(x))
            return x
        else:
            raise ValueError(f'Unknown mode: {self.mode}')
```

## 12.3 动态模态门控（DynamicGate，原 DMG_v2）

```python
class DynamicGate(nn.Module):
    """通道级门控，返回融合后的 tokens 与门控权重 g。"""
    def __init__(self, E=512, learnable_tau=True):
        super().__init__()
        self.tau = nn.Parameter(torch.tensor(2.0)) if learnable_tau else 2.0
        self.scale_f = nn.Parameter(torch.ones(1, E))
        self.scale_v = nn.Parameter(torch.ones(1, E))
        self.mlp = nn.Sequential(
            nn.Linear(2*E + 4, E), nn.ReLU(), nn.Linear(E, E)
        )
    def forward(self, f_tokens, v_tokens, vts_valid):
        # 通道尺度自适应（在 GAP 前）
        f_tokens = f_tokens * self.scale_f.unsqueeze(1)
        v_tokens = v_tokens * self.scale_v.unsqueeze(1)
        f_gap = f_tokens.mean(1)
        v_gap = v_tokens.mean(1)
        f_n = F.normalize(f_gap, dim=-1)
        v_n = F.normalize(v_gap, dim=-1)
        s_f = f_gap.norm(dim=-1, keepdim=True)
        s_v = v_gap.norm(dim=-1, keepdim=True)
        flags = torch.stack([torch.ones_like(vts_valid.float()), vts_valid.float()], dim=-1)  # [B,2]
        g_in = torch.cat([f_n, v_n, s_f, s_v, flags], dim=-1)       # [B, 2E+4]
        logits = self.mlp(g_in)                                           # [B,E]
        g = torch.sigmoid(logits / (self.tau if isinstance(self.tau, torch.Tensor) else torch.tensor(self.tau, device=logits.device)))
        # 缺失硬约束：vts_valid=0 → g=1（退化为 F）
        g = torch.where(vts_valid.view(-1,1).bool(), g, torch.ones_like(g))
        fused = g.unsqueeze(1)*f_tokens + (1-g).unsqueeze(1)*v_tokens     # [B,N,E]
        return fused, g

# 兼容别名（文档处仍称 DMG_v2）
DMG_v2 = DynamicGate
```

## 12.4 时序建模模块（B6专用）

```python
class TemporalTransformer(nn.Module):
    """伪时序 Transformer：将 token 划分为 T 个 chunk，做序列建模后聚合。"""
    def __init__(self, E=512, T=8, num_layers=2, num_heads=8, dropout=0.1):
        super().__init__()
        self.E = E
        self.T = T
        enc_layer = nn.TransformerEncoderLayer(
            d_model=E, nhead=num_heads, dim_feedforward=4*E,
            dropout=dropout, activation='gelu', batch_first=True
        )
        self.encoder = nn.TransformerEncoder(enc_layer, num_layers=num_layers)
        self.pos_encoding = nn.Parameter(torch.zeros(1, T, E))
        nn.init.normal_(self.pos_encoding, std=0.02)

    def forward(self, tokens):  # tokens: [B,N,E]
        B, N, E = tokens.shape
        if self.T <= 1 or N < self.T:
            return tokens.mean(1)
        chunk = N // self.T
        if chunk == 0:
            return tokens.mean(1)
        x = tokens[:, :self.T*chunk, :].reshape(B, self.T, chunk, E).mean(2)  # [B,T,E]
        x = x + self.pos_encoding
        x = self.encoder(x)  # [B,T,E]
        return x.mean(1)     # [B,E]
```

## 12.4.2 B2 专用拼接融合（Zero + Presence Emb + Flag）

```python
class ConcatFusion(nn.Module):
    def __init__(self, E=512, use_flag=True, use_presence_emb=True):
        super().__init__()
        self.use_flag = use_flag
        self.use_presence_emb = use_presence_emb
        self.presence_embed = nn.Parameter(torch.zeros(1, E)) if use_presence_emb else None
        if self.presence_embed is not None:
            nn.init.normal_(self.presence_embed, std=0.02)
    def forward(self, f_tokens, v_tokens, vts_valid):
        f_gap = f_tokens.mean(1)                          # [B,E]
        v_gap = v_tokens.mean(1)                          # [B,E]
        # 缺失处理：先零化，再用 presence embedding 替代 GAP 特征（融合前）
        v_gap = v_gap * vts_valid.view(-1,1)
        if self.use_presence_emb:
            missing = (~vts_valid.bool()).view(-1,1).float()
            v_gap = v_gap + missing * self.presence_embed.expand_as(v_gap)
        feat = [f_gap, v_gap]
        if self.use_flag:
            feat.append(vts_valid.view(-1,1).float())     # 标量 flag
        return torch.cat(feat, dim=-1)                    # [B, 2E(+1)]
```

## 12.6 训练脚本（极简示例）

```python
def train_one_epoch(model, dataloader, optimizer, scaler):
    model.train()
    for fcs, vts, vts_valid, label in dataloader:
        optimizer.zero_grad(set_to_none=True)
        with torch.cuda.amp.autocast():
            out = model(fcs, vts, vts_valid)
            logits = out[0] if isinstance(out, tuple) else out
            loss = F.cross_entropy(logits, label)
        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()
```
