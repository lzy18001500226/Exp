## 1. 全量构建标准化 NPZ（一次性）

脚本：`Tools/float16转float32/build_labeled_npz.py`

功能要点：

- 读取 `.npy`（单通道 float16，形状约 `(543,512)`，值域 `[0,1]`）。
- 统一生成：
  - `spec_raw`（原尺寸，float16）
  - `spec_512`（`512×512`，INTER_AREA 重采样，float32）
  - 可选掩码：`fcs_mask_512` / `vts_mask_512`（uint8）
  - 标注与元信息：`labels`、`meta`（含依赖版本与脚本哈希），`has_fcs/has_vts` 标志
- 子目录按类别 ID（0–23）组织；自然序号来自文件名数值前缀（如 `12-a` → 12）。

用法：

- 查看帮助以确认你的参数：
  - `python C:\Users\HP\Desktop\Exp\Tools\float16转float32\build_labeled_npz.py --help`
- 常见参数（名称以脚本为准）：输入根目录、掩码目录（可选）、输出根目录、并行度、覆盖策略、每类上限等。

> 产物：`C:\Users\HP\Desktop\Exp\Data-512NPZ\{class_id}\*.npz`

## 5. 常见问题（FAQ）

1) 如何指定 14 个 with_vts 类？

- 运行命令中添加 `--include_classes <14 个类ID逗号分隔>` 显式传入；建议将该命令保存到本次 run 目录的 `cmd.txt` 便于复现实验。

2) 运行列表划分后提示 “No items matched …”

- 检查 `--data_root` 是否指向 `Data-512NPZ`（而不是原始 `Data`）。
- 确认类子目录为数字命名（0–23），且包含 `.npz` 文件。
- 检查 `--stem_min/max` 是否覆盖到现有文件的数值前缀（如 `0–200`）。

3) 划分输出数量与预期不符

- 查看 `class_counts_*.json`，确认每类计数是否合理；如需自定义类集，使用 `--include_classes`/`--exclude_classes`。

4) 统计脚本运行缓慢

- 统计是一次性操作，建议仅对训练列表运行；必要时减少直方图 bins 或采用子集抽样（不推荐）。

5) 未来新增标签/样本如何处理？

- 重新执行第 1 步（增量或全量）生成 NPZ；
- 再运行第 2 步划分列表；
- 最后第 3 步重算统计；
- 保留旧 run 目录可用于对照实验。

## 8. 训练阶段增强与确定性配置（已默认开启）

为保证训练阶段的数据分布稳定、可复现，脚本 `scripts/run_b0.ps1` 已将关键增强开关默认开启，并在 `scripts/train.py` 完成参数接线与确定性设置。

- 随机性
  - 全局种子默认 3407，可通过 `-Seed` 覆盖；DataLoader 使用 per-worker 种子；强制 `cudnn.deterministic=True, benchmark=False`。
- 增强顺序与数值稳定
  - 顺序：BgMix → FreqShift → TimeStretch → SpecAug → Noise → clamp[0,1] → 标准化
  - 全程 float32、增强后 `NaN/Inf` 安全处理并裁剪到 `[0,1]`
- 增强默认开关（均为 true，可在 PS 参数中关闭）
  - `-IsTrainAug`：启用训练时增强
  - `-UseBgMix`：背景混合（仅非 class-0，背景来自训练集 class-0）
  - `-UseFreqShift`：频率偏移（整数 bin 位移、零填充、不回卷；±10 MHz 上限）
  - `-UseTimeStretch`：时间拉伸（仅时间轴 1D 线性插值，anti-alias）
  - `-UseNoise`：自适应噪声（sigma=k·std(x)，k∈[0.01,0.05]）
  - `-UseSpecAug`：SpecAug（时间/频率掩蔽比率≤0.2、每轴≤2 个，样本均值填充）
- 带宽与中心频率（重要变更）
  - 带宽（bandwidth_mhz）：训练时可用 `--bandwidth_mhz` 显式指定；若不指定则从 `.npz` 的 `meta/meta_json` 解析。官方标注为 100 MHz，但请以实际数据为准。
  - 中心频率（center_freq_mhz）：由于当前 MAT/NPZ 中均缺失中心频率元数据，已“丢弃/停用”按中心频率分桶的特征与增强。背景混合统一使用“全局 class-0 背景池”，不再进行频段匹配。若未来补写 `center_freq_mhz` 到 NPZ（或提供外部映射），无需改代码即可自动恢复同频段优先匹配。

自检

- 提供 `scripts/check_augs_stats.py`，对训练列表做增强路径统计（无需可视化），输出 `aug_stats.json` 以便快速核对位移/比例/概率是否达标。

## 9. 持续补标与再训练流程

当你新增/修正标注或新增样本时，按以下步骤快速更新训练集并复现实验。以下命令基于 Windows PowerShell；路径与参数按需替换。

步骤 1：划分列表（train/val）

- 核对类集、自然序号范围与验证比例。
- 例（分类任务；排除类 13,14；自然序号 0–200；验证 10%）：

```powershell
# 设定一次运行目录名
$RunName = "200标签训练_$(Get-Date -Format yyyyMMdd-HHmm)"
# 生成列表
python C:\Users\HP\Desktop\Exp\Tools\划分数据集\split_train_val.py `
  --task classification `
  --data_root C:\Users\HP\Desktop\Exp\Data-512NPZ `
  --out_dir   C:\Users\HP\Desktop\Exp\Model\DSFNet-Output `
  --run_name  $RunName `
  --exclude_classes 13,14 `
  --stem_min 0 --stem_max 200 `
  --val_ratio 0.1 `
  --seed 42
```

产物：

- `Model/DSFNet-Output/$RunName/train_list_cls.txt`
- `Model/DSFNet-Output/$RunName/val_list_cls.txt`
- `class_counts_cls.json`（每类计数）

步骤 2：计算归一化统计（只用训练列表）

```powershell
python C:\Users\HP\Desktop\Exp\Tools\全局统计\compute_stats.py `
  --list_file C:\Users\HP\Desktop\Exp\Model\DSFNet-Output\$RunName\train_list_cls.txt `
  --save      C:\Users\HP\Desktop\Exp\Model\DSFNet-Output\$RunName\stats.json
```

产物：`stats.json`（mean/std/p1/p99），训练时通过 `--stats` 传入。

步骤 3：增强自检（推荐）

- 用于确认频移换算的 bin 数、各增强概率与参数范围是否符合预期。
- 注意：若 NPZ 未写 `bandwidth_mhz`，请显式指定 `--bandwidth_mhz`（例如 100）。

```powershell
python C:\Users\HP\Desktop\Exp\DSFNet\scripts\check_augs_stats.py `
  --train_list    C:\Users\HP\Desktop\Exp\Model\DSFNet-Output\$RunName\train_list_cls.txt `
  --bandwidth_mhz 100 `
  --out          C:\Users\HP\Desktop\Exp\Model\DSFNet-Output\$RunName\aug_stats.json
```

产物：`aug_stats.json`（频移估计 bin、时间拉伸范围、SpecAug 参数、噪声 k 范围等）。

步骤 4：启动训练（B0 基线示例）

- 关键参数：`--stats` 指向步骤 2 的统计；如需，显式 `--bandwidth_mhz 100`。

```powershell
python C:\Users\HP\Desktop\Exp\DSFNet\scripts\train.py `
  --train_list  C:\Users\HP\Desktop\Exp\Model\DSFNet-Output\$RunName\train_list_cls.txt `
  --stats       C:\Users\HP\Desktop\Exp\Model\DSFNet-Output\$RunName\stats.json `
  --num_classes 22 `
  --epochs 30 --batch_size 16 --amp `
  --backbone_lr 1e-4 --head_lr 1e-3 --weight_decay 0.05 `
  --freeze_backbone_epochs 5 --label_smoothing 0.1 --clip_grad 1.0 `
  --is_train_aug --use_bg_mix --use_freq_shift --use_time_stretch --use_noise --use_specaug `
  --bg_mix_p 0.5 --alpha_min 0.1 --alpha_max 0.3 `
  --freq_shift_p 0.8 --shift_mhz 10.0 `
  --time_stretch_p 0.8 --time_scale_min 0.9 --time_scale_max 1.1 `
  --noise_p 0.5 --noise_k_min 0.01 --noise_k_max 0.05 `
  --specaug_p 0.5 --specaug_time_ratio 0.2 --specaug_freq_ratio 0.2 --specaug_num_masks 2 `
  --bandwidth_mhz 100
```

产物：`Run-B0-YYYYMMDD-HHMM/` 下的日志与权重（best.pt/last.pt/log.csv/config.yaml/metrics.json）。

注意事项

- 中心频率（center_freq_mhz）已停用：MAT/NPZ 缺失该元数据，背景混合统一使用“全局 class-0 背景池”。未来若补齐 `center_freq_mhz`，现有代码会自动恢复“同频段优先匹配”。
- 带宽（bandwidth_mhz）：若 NPZ meta 中不存在该字段，请在步骤 3、步骤 4 中显式传入（如 100）。频移 bin 近似为 `bins = round(shift_mhz * 512 / bandwidth_mhz)`。
- 数据健康检查：
  - 抽样打开若干 `.npz`，应包含键：`spec_512`（float32, 512×512）、`label_class_id`、`meta_json`。
  - `spec_512` 数值范围应在 `[0,1]`；如超界，需检查上游归一化流程。
- 列表再生成：每次补标或增样后，仅需重复步骤 1–2 即可；其他步骤按需执行。

### 10.2 标注解析

  1) 直接给出 `{"boxes": [[x,y,w,h], ...]}`（像素或已归一化，像素将除以 512）
  2) LabelMe 风格 `{"shapes": [{"points": [[x1,y1],[x2,y2],...]}, ...]}`，取外接矩形后归一化
- 类别 ID 从父目录名 `<cls>` 解析。

### 10.3 图像预处理（对齐 SMNet 与 ImageNet 预训练）
- 对单通道 `spec_512` 做样本级 min-max：`(x - min) / (max - min) * 255`
- 复制为 3 通道，转到 [0,1] 后做 ImageNet 标准化：
  - mean = [0.485, 0.456, 0.406]，std = [0.229, 0.224, 0.225]
- 说明：检测不使用 `stats.json` 的全局均值方差；严格按样本级 min-max + ImageNet 规范。

### 10.7 StemMin/StemMax过滤（新增功能）

**功能**：在PowerShell启动脚本内按stem范围过滤train/val列表，减少训练时间。

**使用方法**（`run_b1_det.ps1`）：
```powershell
.\scripts\run\run_b1_det.ps1 -StemMin 0 -StemMax 100 -HeadOutUp 4 -BatchSize 2
```

**实现细节**：
- 使用正则 `\(\d+\)[^\]+\.json$` 从JSON路径提取stem数字
- PowerShell `Where-Object` 过滤满足 `$stem -ge $StemMin -and $stem -le $StemMax` 的行
- 生成新列表：`train_list_vts_stem0-100.txt`（示例）
- 显示过滤前后文件数

**示例输出**：
```
Stem Range: 0-100
Filtered train: 271 files (from 543)
Filtered val: 30 files (from 60)
```

**优势**：
- 快速验证：0-100可减少约50%训练时间
- 复现实验：固定stem范围保证可复现
- 无需修改原列表：过滤后的列表独立保存
